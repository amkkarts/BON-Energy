# BON Energy Website

Static HTML/CSS/JS implementation of the BON Energy Electric Mini Excavators homepage.

## Files
- `index.html` — semantic website structure and source content
- `styles.css` — responsive visual design
- `script.js` — mobile navigation, active navigation state and demo quote-form handling
- `assets/` — visual placeholder images derived from the provided website design reference

## Run
Open `index.html` directly in a browser, or serve the folder with any static HTTP server.

Example:
`python3 -m http.server 8000`

Then visit:
`http://localhost:8000`

## Important
The supplied BON Energy PDF explicitly says specifications, performance figures and imagery are to be finalized after engineering validation. No unsupported technical figures, prices, warranty durations, certifications, testimonials or contact details have been invented here.

Replace the placeholder image assets with approved BON Energy photography when available.
